# Imaimai Portfolio

[imaim.ai](https://imaim.ai)

imaimai17468 のポートフォリオサイト。`index.html` と `style.css` だけで構成された静的サイト。

## 構成

| ファイル | 役割 |
|---------|------|
| `index.html` | 全コンテンツ（Skills / Projects / History / Links） |
| `style.css` | スタイル |

## ローカル確認

ビルドは不要。`index.html` をブラウザで直接開くか、任意の静的サーバーで配信する。

```bash
python3 -m http.server
```

## デプロイ

Vercel（Framework Preset: Other）。`main` へのマージで自動デプロイされる。
